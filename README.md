## API Endpoints

| Метод | URL | Назначение |
|---|---|---|
| GET | / | Проверка работы |
| GET | /api/info | Информация о приложении |
| GET | /api/rooms | Список номеров |
| GET | /api/rooms/{id} | Номер по Id |
| GET | /api/rooms?search=... | Поиск |
| POST | /api/rooms | Создать номер |
| PUT | /api/rooms/{id} | Обновить номер |
| DELETE | /api/rooms/{id} | Удалить номер |
